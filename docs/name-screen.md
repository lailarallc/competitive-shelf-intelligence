for the name beside "hot sauce", "foods" and "brand". No search returned a
business, product or brand using the name.

Limits: this is a web-search screen. It is not a trademark search and not
legal clearance. Re-screen before adding a name, and replace any name that
later turns out to belong to a real business.

Retailer sites are shown as role labels ("Online marketplace", "Mass retailer
site"), which need no screen.
